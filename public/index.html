Запуск оригинального парсера (Без API)

Так как Vercel не запускает браузер Chrome напрямую, полный сбор карточек parser-2gis.py выполняется на бесплатном сервере GitHub Actions (2000 бесплатных минут в месяц, без токенов и API).

  1. Скопируй сгенерированные ссылки на первой вкладке.
  2. Нажми «Открыть GitHub Actions» (откроется вкладка Run 2GIS Parser).
  3. Нажми кнопку Run workflow, вставь ссылки и выбери xlsx или csv.
  4. Через 1–3 минуты скачай готовый Excel-файл прямо в телефон в блоке Artifacts!
Установка иконки на главный экран

На iPhone (iOS Safari):

  1. Открой эту ссылку на Vercel в браузере Safari.
  2. Нажми кнопку «Поделиться» (квадрат со стрелкой вверх внизу экрана).
  3. Прокрути меню вниз и выбери «На экран „Домой“» (Add to Home Screen).
  4. Нажми «Добавить» — на рабочем столе появится фирменная иконка 2GIS Parser во весь экран.

На Android (Chrome):

  1. Нажми на три точки в правом верхнем углу браузера Chrome.
  2. Выбери «Установить приложение» или «Добавить на главный экран».
